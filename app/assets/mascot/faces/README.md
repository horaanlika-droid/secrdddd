# Эмоции · только голова Дибитишки

Все 16 выражений получены **из одной генерации 4×4**, не из отдельных картинок.
Исходный лист: `scripts/art-src/mood-heads-sheet.webp`.
Нарезка: `python3 scripts/build-mood-faces.py` (Pillow).

Сетка `sheet.webp` и PNG имеют прозрачный фон; каждая ячейка 256×256.
**Интерфейс использует только один файл `sprite.webp`** (512×512, 4×4,
ячейка 128×128). CSS выбирает нужную ячейку; нет отдельных загрузок PNG
для каждой эмоции. Скрипт получает спрайт из того же листа, без новой генерации.
Полноразмерный `sheet.webp` и PNG-нарезка сохранены для просмотра и бота.

Ряды слева направо:

1. `hard` — тяжело, `sad` — грустно, `anxious` — тревожно, `even` — ровно.
2. `warm` — тепло, `fun` — весело, `joy` — радостно, `mixed` — смешанно.
3. `unclear` — непонятно, `angry` — сердито, `surprised` — удивлённо, `calm` — спокойно.
4. `sleepy` — сонно, `curious` — любопытно, `proud` — гордость, `love` — с любовью.

В дневнике используются первые девять состояний, без изменения индексов шкалы.
Остальные семь — резерв; их появление в листе не меняет старые записи.
