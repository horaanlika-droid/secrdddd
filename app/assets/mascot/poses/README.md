# Маскот · извлечённые ассеты

Автоматически извлечено из папки «элементы нового дизайна для переработки и вдохновения».
Инструмент: ImageMagick — белый фон → прозрачность (заливка с краёв), кроп по контенту,
уборка «ножек»/хвостиков снизу.

## Основные рендеры

| Файл | Источник | Размер | Где используется |
|---|---|---|---|
| `hero.png` | IMG_0966.jpeg | 1234×517 | `app/assets/mascot/proud.png`, `hug.png`, бот `proud/hug` — поза с разведёнными ручками |
| `side.png` | IMG_0969.jpeg | 860×592 | `app/assets/mascot/hello.png`, `calm.png`, `peek.png`, бот `hello/calm` — поза стоя |

У капельки только ручки, ножек нет: у `hero.png` обрезан хвостик снизу (на y=739 исходника),
у `side.png` — на y=593.

## Спрайт-листы (60 шт.)

- `sprite-01…30.png` ← IMG_0965.jpeg
- `sprite-31…60.png` ← IMG_0967.png
- Размер 82–178 px, прозрачный фон.

Хвостики/выступы снизу обрезаны у 13 спрайтов: `sprite-06, 21, 33, 35, 43, 44, 45, 48, 50, 51, 52, 54, 59`.
