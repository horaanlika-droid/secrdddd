# Доска впечатлений · творческий беспорядок

`creative-mess.webp` — новая иллюстрация страницы досок: свободная композиция
из обрывков бумаги, скотча, фото, плёнки, ракушек, морского стекла, бусин,
ленточек, билетов, цветка, карандаша и маленьких талисманов. Элементы намеренно
перекрываются и лежат под разными углами; внешней рамки у композиции нет —
фон растворяется в интерфейсе, поэтому сам экран ощущается доской.

`creative-mess-thumb.webp` — облегчённая версия для тизера на главной.
Персонаж основан на `assets/mascot/hello.png`.

Обе картинки статичны. Это иллюстрация интерфейса, не пользовательская доска;
она не добавляется в записи и не синхронизируется как личное фото.
Большой исходник генерации остаётся вне Git (`_source/`).

`seaside-keepsakes*.webp` сохранены как предыдущая версия иллюстрации.
