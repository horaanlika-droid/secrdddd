# Доска впечатлений · морские воспоминания

`seaside-keepsakes.webp` — одна AI-сгенерированная композиция для страницы досок:
ракушки, камушек, морское стекло, браслет и подвески, фантики, билеты и полароид
с Дибитишкой у моря. Персонаж основан на `assets/mascot/hello.png`.
`seaside-keepsakes-thumb.webp` — облегчённая версия для тизера на главной.

Обе картинки статичны. Это иллюстрация интерфейса, не пользовательская доска;
она не добавляется в записи и не синхронизируется как личное фото.
Большой исходник генерации остаётся вне Git (`_source/`).
