> **Это итерация номер 45** (16.09.2026).
>
> - **У музыки появилась земля: настоящие записи природы.** Экран `#/sound` больше
>   не играет один только синтез: под полотном звучит запись своей сцены — прибой,
>   дождь по стеклу, треск очага, утренний лес, река в колыбельной, гул космоса.
>   Семь файлов `app/assets/ambience/*.m4a` — 2,53 МБ вместе (321–521 КБ на сцену
>   и 76 КБ колокольчиков), AAC 48 кГц моно: этот контейнер играет везде, включая
>   WKWebView в Telegram на iPhone, где Ogg/Opus нет. Записи открытые (CC0 1.0),
>   происхождение каждой описано рядом с файлами — `app/assets/ambience/LICENSES.md`.
> - **Запись — это две копии бесшовной петли.** Петли собраны кроссфейдом «хвост в
>   голову» с нормировкой по RMS и длятся 32–52 с; движок запускает две копии с
>   разными случайными точками входа, разводит их по стереополю, срезает низ
>   фильтром под музыку и даёт каждой своё медленное дыхание (25–49 с). Поэтому
>   даже короткая петля не читается как петля.
> - **Скачивается один раз и по одной сцене.** Файл текущей сцены грузится при
>   старте, следующая по списку подгружается в простое (`requestIdleCallback`),
>   расшифрованное остаётся в кэше — возврат к уже звучавшей сцене мгновенный.
>   Никаких стримингов и внешних адресов: звук лежит в репозитории, значит
>   гео-блокировки и чужие CDN ему не страшны.
> - **Голос — мотив поверх полотна.** Третий слой: мотив из 3–5 нот собирается один
>   раз на сессию и дальше не повторяется, а каждая фраза переносится в текущий
>   аккорд и остаётся в ладу сцены (все аккорды — ступени того же лада, нота либо
>   тон аккорда, либо проходящая, фраза кончается устойчивой ступенью). Внутри
>   аккорда одна-две фразы, между ними 8–34 с по сцене; сами ноты дышат:
>   длительности 1,4/2,2/3,1/4,2 с (последняя в полтора раза длиннее), паузы
>   0,9–2,4 с, человеческие сдвиги ±60–90 мс, субголос на 45 % тише, тембр — четыре
>   частичных тона со срезом 3,2 кГц и длинным хвостом. Ручка «Голос» убавляет слой
>   или выключает его вовсе.
> - **Живые акценты.** Раз в 40–180 с (у каждой сцены свой интервал) приходит
>   настоящий удар колокольчиков — та же открытая запись, тихо (0,04–0,08) и с эхом.
> - **Запасной шум не удалён.** Он собирается из веток шума, как раньше, и звучит с
>   первой же секунды; запись сменяет его кроссфейдом 2,2 с. Без сети, в старом
>   вебвью или если декодер ошибся — воздух остаётся шумовым, музыка играет дальше,
>   а экран честно пишет «запасной шум».

Приложение для развития навыков осознанности через техники ДПТ — с отслеживанием успехов
и подкреплением развития навыков. Для нейроотличных людей и всех, кого накрывает.
Первая неделя бесплатно, дальше — минимальный донат раз в месяц через Tribute.

- **Веб**: статика в `app/` → GitHub Pages; в Телеграме открывается как Mini App.
  По адресу сайта открывается приложение, а не README: корневой `index.html` редиректит
  в `app/index.html` (с сохранением `#hash` для Telegram), `.nojekyll` выключает Jekyll.
- **Бот**: `bot/` (Node.js + grammY) — актуализация любого блока контента, рассылки
  с вырезанием белого фона, коды входа для веба, пуши-напоминания, Tribute, статус подписки.
- **Зависимости сами**: точка входа `bot/src/index.js` сначала проверяет и при нужде
  доустанавливает пакеты (`src/ensure-deps.js`) — `Cannot find package 'grammy'` больше
  не роняет контейнер по кругу. Сборка Docker и CI это контролируют: `npm run check`,
  `npm run smoke`.
- **Порт сам**: при деплое `src/port.js` находит того, кто держит порт; если это наша
  прошлая копия — просит её уйти и занимает порт сам (чужие процессы не трогает,
  а берёт следующий свободный). По SIGTERM база пишется сразу и порт освобождается.
  Проверка: `npm run port`.
- **Маскот**: дибитишка — слезинка без ножек, с big eyes и румянцем, сопровождает пользователя,
  оставляет точки контакта и приходит в пушах.
- **Тетрадь**: рабочая тетрадь ДПТ, переписанная от лица дибитишки; печатается из `workbook.html`
  (3 страницы превью бесплатно, полная — по подписке) или заказывается в мерче
  (концепт-мокапы без фона, заказ через @vasmedoljno).
- **Прелоад**: авторская подпись встроена только в растровый splash-арт.

Быстрый старт: [docs/SETUP.md](docs/SETUP.md) — три переменные на бот-хосте и всё.

Палитра: Sophinka Design (lavender / leaf / grass / jungle / sky / cacao / peony / dusty rose),
причёсанная под тренды 2026–27: low-stimulus calm UI, мягкие диффузные градиенты,
стекло только на оверлеях. Тёмная тема отключена (приложение светлое), но есть
две светлые палитры — «голубая» и «розовая»; переключаются в профиле.
