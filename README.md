Приложение для развития навыков осознанности через техники ДПТ — с отслеживанием успехов
и подкреплением развития навыков. Для нейроотличных людей и всех, кого накрывает.
Первая неделя бесплатно, потом 200 ₽ в месяц (Tribute).

- **Веб**: статика в `app/` → GitHub Pages; в Телеграме открывается как Mini App.
  По адресу сайта открывается приложение, а не README: корневой `index.html` редиректит
  в `app/index.html` (с сохранением `#hash` для Telegram), `.nojekyll` выключает Jekyll.
- **Бот**: `bot/` (Node.js + grammY) — актуализация любого блока контента, рассылки
  с вырезанием белого фона, коды входа для веба, пуши-напоминания, Tribute, статус подписки.
- **Зависимости сами**: точка входа `bot/src/index.js` сначала проверяет и при нужде
  доустанавливает пакеты (`src/ensure-deps.js`) — `Cannot find package 'grammy'` больше
  не роняет контейнер по кругу. Сборка Docker и CI это контролируют: `npm run check`,
  `npm run smoke`.
- **Порт сам**: при деплое `src/port.js` находит того, кто держит порт; если это наша
  прошлая копия — просит её уйти и занимает порт сам (чужие процессы не трогает,
  а берёт следующий свободный). По SIGTERM база пишется сразу и порт освобождается.
  Проверка: `npm run port`.
- **Маскот**: дибитишка — слезинка без ножек, с big eyes и румянцем, сопровождает пользователя,
  оставляет точки контакта и приходит в пушах.
- **Тетрадь**: рабочая тетрадь ДПТ, переписанная от лица дибитишки; печатается из `workbook.html`
  (3 страницы превью бесплатно, полная — по подписке) или заказывается в мерче (заглушка).
- **Прелоад**: авторская подпись встроена только в растровый splash-арт.

Быстрый старт: [docs/SETUP.md](docs/SETUP.md) — три переменные на бот-хосте и всё.

Палитра: Sophinka Design (lavender / leaf / grass / jungle / sky / cacao / peony / dusty rose),
причёсанная под тренды 2026–27: low-stimulus calm UI, мягкие диффузные градиенты,
стекло только на оверлеях. Тёмная тема отключена (приложение светлое), но есть
две светлые палитры — «голубая» и «розовая»; переключаются в профиле.
