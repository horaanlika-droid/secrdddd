# дибитишка 💧

> **Это итерация номер 24** (15.09.2026).
> Что изменилось:
> - **«Чат молчит» теперь имеет причину.** `GET /health` отдаёт `telegram.polling`
>   (running / retry / dead + `poll_error: conflict|auth|network`), `ai_health`
>   (модель, счётчики, последняя ошибка и текст из ответа OpenAI), `problems[]`
>   человеческим языком и путь к базе. В Telegram — команды `/diag` (полный разбор
>   с тестовым звонком модели) и `/ai` (кратко). На хосте — `npm run ai-check`
>   (ключ, модель, getMe, живой /chat), из любой точки — `npm run ai-check -- --url https://…`.
>   Это закрывает главный тупик прошлых раскопок: HTTP жил и говорил «ai: true»,
>   а Telegram читала старая копия бота (409) — выглядело как «OpenAI не отвечает».
> - **Ошибки OpenAI перестали притворяться перегрузкой.** `insufficient_quota`
>   (кончились деньги) больше не маскируется под «меня слишком много спрашивают»;
>   404 модель, 401 ключ, 403 регион и таймаут разделены, каждый — со своей
>   подсказкой (`ai.errorHint`).
> - **Свежие модели работают без правок.** `gpt-5*`/`o*` не принимают
>   `max_tokens` и `temperature` и отвечают 400. Теперь режим подстраивается сам
>   (переход на `max_completion_tokens`, режим запоминается), а при переполнении
>   контекста история укорачивается и запрос повторяется. Проверка — `npm run ai-test`
>   (подставной OpenAI, без сети и ключей).
> - **Техничка не лезет в чат поддержки.** Гостю — тёплый ответ из его записей,
>   владельцу — причина отдельным сообщением (ключ, деньги, модель). В вебе под
>   ответом появилась тихая строка «живой голос на паузе: <причина>», тап по ней
>   перепроверяет связь. Раньше отказ API прятался за шаблоном, и это выглядело
>   как «ии не реагирует».
> - **Открытый `POST /chat` получил лимит** (`CHAT_RATE_PER_MIN`, по умолчанию 20/мин
>   на IP) — иначе один скрипт съедал бюджет ключа владельца.
> - **Порт и выход починены** (регрессия, из-за которой CI был красный): `app.js`
>   снова занимает порт через `acquirePort` (своя прошлая копия уходит, чужой
>   процесс не трогается, при чужом порте — переход на следующий) и корректно
>   закрывается по SIGTERM с немедленной записью базы. `bot/src/free-port.js`
>   удалён: он убивал любой процесс на порту, включая чужие.
> - **Главный `index.html` больше не теряет `#hash`** — Telegram Mini App передаёт
>   `tgWebAppData` во фрагменте URL; с `<meta refresh>` веб открывался гостем,
>   то есть чат без имени, записей и памяти диалога.

Приложение для развития навыков осознанности через техники ДПТ — с отслеживанием успехов
и подкреплением развития навыков. Для нейроотличных людей и всех, кого накрывает.
Первая неделя бесплатно, потом 200 ₽ в месяц (Tribute).

- **Веб**: статика в `app/` → GitHub Pages; в Телеграме открывается как Mini App.
  По адресу сайта открывается приложение, а не README: корневой `index.html` редиректит
  в `app/index.html` (с сохранением `#hash` для Telegram), `.nojekyll` выключает Jekyll.
- **Бот**: `bot/` (Node.js + grammY) — актуализация любого блока контента, рассылки
  с вырезанием белого фона, коды входа для веба, пуши-напоминания, Tribute, статус подписки.
- **Зависимости сами**: точка входа `bot/src/index.js` сначала проверяет и при нужде
  доустанавливает пакеты (`src/ensure-deps.js`) — `Cannot find package 'grammy'` больше
  не роняет контейнер по кругу. Сборка Docker и CI это контролируют: `npm run check`,
  `npm run smoke`.
- **Порт сам**: при деплое `src/port.js` находит того, кто держит порт; если это наша
  прошлая копия — просит её уйти и занимает порт сам (чужие процессы не трогает,
  а берёт следующий свободный). По SIGTERM база пишется сразу и порт освобождается.
  Проверка: `npm run port`.
- **Маскот**: дибитишка — слезинка без ножек, с big eyes и румянцем, сопровождает пользователя,
  оставляет точки контакта и приходит в пушах.
- **Тетрадь**: рабочая тетрадь ДПТ, переписанная от лица дибитишки; печатается из `workbook.html`
  (3 страницы превью бесплатно, полная — по подписке) или заказывается в мерче (заглушка).
- **Прелоад**: авторская подпись встроена только в растровый splash-арт.

Быстрый старт: [docs/SETUP.md](docs/SETUP.md) — три переменные на бот-хосте и всё.

Палитра: Sophinka Design (lavender / leaf / grass / jungle / sky / cacao / peony / dusty rose),
причёсанная под тренды 2026–27: low-stimulus calm UI, мягкие диффузные градиенты,
стекло только на оверлеях. Тёмная тема отключена (приложение светлое), но есть
две светлые палитры — «голубая» и «розовая»; переключаются в профиле.
