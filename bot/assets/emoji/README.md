# Эмодзи-пак Дибитишки · для Telegram Premium 💧

20 custom emoji — лица эмоций и позы маскота, которыми можно ставить
реакции прямо внутри текста сообщения. Вставлять эмодзи в сообщения и
добавлять паки умеет **Telegram Premium**; создать и опубликовать пак
может любой аккаунт или бот.

## Что лежит в папке

| Файл | Зачем |
|---|---|
| `*.png` (20 шт.) | сами эмодзи: **ровно 100×100 px**, RGBA с прозрачным слоем, ≤ 64 КБ каждый, без ICC/EXIF |
| `*.webp` (20 шт.) | те же картинки в WEBP — альтернатива, если PNG чем-то не подошёл |

## Вариант 1 · опубликовать своим аккаунтом через @Stickers

1. В Telegram открой **@Stickers** → `/newemojipack`.
2. Введи название пака, например `Дибитишка · эмоции`.
3. Загружай файлы `*.png` **как File** (не как фото), по одному; после каждого
   бот попросит ярлык — отправь базовый эмодзи из таблицы выше.
4. Когда все 20 загружены — `/publish`, иконку можно `/skip`.
5. Получишь ссылку вида `t.me/addemoji/<имя>` — по ней пак ставится в два тапа.
   Дальше в любом сообщении: панель эмодзи → твой пак → тап по Дибитишке.

## Вариант 2 · опубликовать ботом (Bot API)

Админ бота: `/publish_emoji` в личных сообщениях. Бот создаст набор
`dibitishka_faces_v1_by_<username бота>` через `createNewStickerSet`
со `sticker_type = "custom_emoji"` и пришлёт ссылку `t.me/addemoji/…`.
Имя детерминированное: повторный запуск после сбоя дойдёт в тот же набор,
а не создаст второй. Меню с превью и кнопками — команда `/emoji`.

## Требования Telegram (почему файлы именно такие)

- статический custom emoji — **ровно 100×100 px**, квадрат, `.PNG` или `.WEBP`;
- прозрачный слой обязателен, иначе эмодзи поплывёт на тёмной теме;
- без ICC-профиля и EXIF — с ними загрузка отклоняется как «Unsupported format»;
- вес держим ≤ 64 КБ: официальный потолок выше, но строгие клиенты
  начинают ругаться раньше, а квантование до 256 цветов на 100 px невидно.

## Как пересобрать

Картинки не генерируются заново — нарезаются из готовых лиц
(`bot/assets/mascot/faces/*.png`) и поз (`bot/assets/mascot/*.png`),
то есть пак всегда совпадает с маскотом приложения:

```bash
.venv/bin/python scripts/build-emoji.py        # PNG + WEBP + manifest + preview
npm run emoji-test                              # проверка формата и публикации (чистый Node)
```

Сборка перезаписывает `manifest.json`, поэтому после правок списка эмодзи
в `scripts/build-emoji.py` меню бота (`/emoji`) подхватит изменения само.
