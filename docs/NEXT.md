## Решение по плееру

Стриминг внутрь приложения не встраивали. Проверено: страница исполнителя
отдаёт «Yandex Music is currently not available in your region» — без
подписки каталог открыт только в РФ и части СНГ, а значит у пользователя
в Европе внутри нашего экрана была бы гео-заглушка вместо звука; плюс
виджет требует логина для полных треков и не работает офлайн.

Вместо этого сделан **собственный генератор на Web Audio**: бинауральный
ритм — это не запись, а эффект восприятия, поэтому аудиофайл не нужен
в принципе. Два синуса с разницей меньше 30 Гц раскладываются по каналам,
и пульс «собирается» в голове. Ноль мегабайт ассетов, офлайн, без лицензий
и без зависимости от региона.

## Сделано

- [x] `app/js/sound.js` — чистая математика тонов (`tonePair`, границы
      несущей 80–950 Гц и пульса 0,5–28 Гц) и движок `createBinauralEngine`
      с подставляемым `AudioContext`: два осциллятора в разные входы
      `ChannelMerger(2)`, мастер-громкость, розовый шум через lowpass как
      подложка, нарастание 4 с, затухание 8 с перед концом таймера.
- [x] Экран `#/sound`: объяснение эффекта схемой с живыми частотами,
      предупреждение «Нужны наушники», четыре пресета (тета 6 / дельта 2 /
      альфа 10 / бета 15 Гц), длительность 5–60 минут, громкость, высота
      тона, подложка шума, большой плеер с отсчётом и паузой, честный блок
      про умеренность эффекта и осторожность при эпилепсии.
- [x] Тизер `.sound-teaser` на «Сегодня» — между «Доской впечатлений» и

## Что нельзя подтвердить из песочницы

- [ ] **Звук на реальном телефоне.** В песочнице нет Chromium и аудиоустройства:
      `npx playwright install chromium` падает на загрузке, поэтому
      `npm run browser-test` здесь не запускался. Частоты, каналы, таймер и
      затухание проверены на записывающем моке Web Audio в `sound-test` и
      `dom-smoke`; как это слышно в наушниках (и как ведёт себя AudioContext
      в Telegram WebView на iOS после блокировки экрана) — только на устройстве.
- [ ] **Фоновое воспроизведение.** Когда экран телефона гаснет, вебвью может
      приостановить AudioContext; без Media Session API и service worker
      обещать игру «в фоне» нельзя. Это сознательно не обещано в интерфейсе.
