## Что нельзя подтвердить из песочницы

- [ ] **Реальные iOS Safari / Telegram WebView / Android Chrome:** системная
      галерея, HEIC конкретного телефона, sheet-фокус/клавиатура, нативная печать.
      Chromium-эмуляция и синтетические EXIF-фото не заменяют телефон.
- [ ] **Живой бот после деплоя:** вход по `/code`, два реальных устройства,
      постоянный том `DB_FILE` + `BOARDS_DATA_DIR`, права на закрытый S3-бакет,
      если выбран S3. Контракт/ошибки/изоляция проверены локально, реальные
      настройки владельца не менялись. Без постоянного диска нельзя обещать
      сохранность при пересоздании контейнера.
- [ ] **Живой Tenor:** нужен `TENOR_API_KEY` в окружении бота. Код интеграции
      и fallback проверены без живого ключа; в его отсутствие приложение
      честно предлагает вставить ссылку.
