# Yo Kit — презентация концепта мини-приложения для «Столярочки Yo»

Концепт Telegram Mini App, в котором клиент мастерской собирает мебель как конструктор:
листы-заготовки из портфолио, параметрический чертёж, материалы цеха, эскиз и заявка-
спецификация в чат с мастером. Визуальный язык — лист ватмана: миллиметровка, кольца кофе,
штампы и малярный скотч поверх точной сетки мини-аппа.

## Что лежит

- `yo-kit-presentation.pdf` — **итог**: 18 листов 1920×1080 (питч: контекст → идея → экраны → механика → внедрение → контакты).
- `miniapp/index.html` — кликабельный мокап, 9 экранов (заставка, каталог, конструктор, материалы, эскиз, заявка, чат, заказы, профиль). Чертежи изделий — параметрическая SVG-изометрия, считается из габаритов и модулей.
- `deck/index.html` — исходник дека (те же токены ватмана, экраны в чертёжных рамках).
- `screenshots/` — кадры экранов 390×844 @2x, сняты с живого мокапа.
- `tools/shot.mjs` — съёмка скриншотов (headless Chromium из `@sparticuz/chromium`, системных браузеров в песочнице нет).
- `tools/pdf.mjs` — печать дека в PDF (`--shots=1,5,7` снимет указанные листы в /tmp для проверки).
- `tools/serve.mjs` — превью: `/` — мини-апп, `/deck` — дек.
- `deck/assets/qr-tg.png` — QR на t.me/stolyarochka_yo.

## Пересобрать

```bash
npm i --no-save @sparticuz/chromium @fontsource-variable/manrope @fontsource-variable/jetbrains-mono qrcode
node presentation/tools/shot.mjs          # скриншоты экранов
node presentation/tools/pdf.mjs           # PDF дека
node presentation/tools/serve.mjs         # локальное превью :8090
```

Инструменты сами распаковывают библиотечный набор Chromium (`al2023.tar.br`) и шрифты
пакета в `/tmp`, если песочница их почистила.

## Решения, зафиксированные с заказчиком

- Формат итога — PDF; обзорные слайды плиткой + ключевые экраны крупно в рамке.
- Темы Telegram-тёмной нет: лист ватмана, «футуризм + честная работа руками».
- Фотографий в UI нет: портфолио живёт на designyo.ru, в мини-аппе — изометрические чертежи и ссылка на сайт.
- Цен в приложении нет: трудоёмкость (м², детали, недели), точную смету и договор присылает мастер.
